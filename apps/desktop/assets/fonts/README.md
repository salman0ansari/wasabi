# Bundled UI font

wasabi bundles Inter 4.1 variable regular and italic fonts for consistent, legible desktop typography. Inter is Copyright 2016 The Inter Project Authors and is distributed under the SIL Open Font License 1.1; see [`LICENSE.txt`](LICENSE.txt).

San Francisco is intentionally not bundled. Apple's font license restricts it to Apple-platform user interfaces and mockups, which is incompatible with wasabi's Linux-first distribution.
